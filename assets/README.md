# Nassets website assets

This folder contains the shared logo asset. Product photography is currently loaded from stable Unsplash image URLs in the stylesheet and page markup so the GitHub Pages site does not depend on missing local JPG files. Replace these with client-approved product photos before production launch.

## Structure
- `css/style.css` — responsive styling, brand colours, motion and layout
- `js/main.js` — navigation, reveal animations, year and enquiry draft behaviour
- `nassets-logo.svg` — editable vector logo placeholder based on the current plum/gold identity

**Brand note:** The SVG logo is a temporary vector placeholder, not a verified original logo file. Replace it with the official client logo when available.
